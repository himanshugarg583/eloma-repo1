# Eloma Group Website

Premium cinematic corporate group website built with Next.js 14, Tailwind CSS, GSAP, Framer Motion, and React Three Fiber.

## Getting Started

1. Install dependencies

```
npm install
```

2. Start the development server

```
npm run dev
```

3. Build for production

```
npm run build
```

## Notes

- Subsidiary data is in lib/data.ts. Replace placeholders with official company details.
- Brand assets can be added to the public/ folder and referenced in components.
